# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.
`CLAUDE.md` non-negotiables win over anything here.

## Aesthetic reference

- **Standard:** Notion
- **Notes:** Warm paper, editorial type, calm spacing. Ledger's own tokens in `src/design/tokens.css` are the
  source of truth: ivory `#faf9f5` paper, near-black `#141413` ink, clay `#d97757` for emphasis, Newsreader
  serif for figures and headings, Albert Sans for interface text. Flat: borders give depth, never shadows.
  Numbers are the content; one clear figure per block beats many equal boxes.

## Banned anti-aesthetics

- Shadows of any kind (`box-shadow`, `drop-shadow`), including "soft" elevation
- Gradients, decorative or otherwise, and neon or glowing borders
- Glassmorphism / `backdrop-filter`
- Emoji anywhere in the interface
- All-caps labels and tracked-out eyebrows
- Floating pastel pill badges for ordinary metadata
- Multi-colour or rainbow CTAs
- Cartoon empty-state illustrations (people waving or high-fiving); the pencil doodles stay
- Nested scrollbars and icon bloat inside inputs
- Rows of identical equal-weight cards where one figure should lead

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text, 3:1 for large text, borders and chart marks, in light and dark.
- **Touch / focus:** 44×44px targets; `:focus-visible` ring is 2px `--accent` with 2px offset. Privacy mode
  hides every amount, including aria-labels, tooltips, toasts and the title. Reduced motion respected.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain, kind, specific, never cute. Say what happened and what to do next; no blame, no
  apology. Indian context: ₹, UPI, udhaar, EMI are normal words here. Every new string goes through `tl()`
  and gets Telugu and Hindi entries.

## Icon library

- **Library:** Project SVG
- **Package / path:** `src/app/icons.tsx` (24px grid, 1.5 stroke, `currentColor`)
- **Notes:** Add new icons to that file in the same style. No icon packages, no mixing sets, no emoji.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Deletes are undoable through the CommandBus and say so in the toast ("Deleted. Undo"). A named
   confirmation dialog is required only where undo cannot help: replacing everything from a backup,
   removing the PIN, wiping data.
6. Stay inside the size budgets in `scripts/budget.mjs` (CSS 16 KB, start-up JS 160 KB).
